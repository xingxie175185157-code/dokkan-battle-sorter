使用说明 / 规则与扩展

一、排序规则
队伍固定 7 个槽位（1~7）＝自己的 6 人 + 好友助战 1 人。每回合取从「起始槽位」开始的连续 3 个槽位上场，起始槽位每回合向后移动 3 格并循环：
第 1 回合 1-2-3 → 第 2 回合 4-5-6 → 第 3 回合 7-1-2 → 第 4 回合 3-4-5 → 第 5 回合 6-7-1 → …
因为自己是 6 人、助战另算，同一个角色允许出现两张（自己一张 + 助战一张），最多两张。

二、交换与连锁影响
把本回合的 3 张卡拖动到另一张卡上，即交换这两人的槽位归属。因为角色是绑定在槽位上的， 被交换的槽位在后续回合再次上场时，带出的就是交换后的角色 —— 所以任何一次调整都会向下重算该回合之后的全部回合。
队伍区里从角色库拖卡进格子是放入语义：这张卡落在该槽位（原来的角色被替换）。 同一张卡可以从库里再拖一次，放进另一个槽位 —— 那就是「自己一张 + 助战一张」的同名双角色。

三、回合数
默认自动推演 5 回合；可输入任意数字后点「应用」，或用 ＋1 / ＋5 / ＋10 持续向下延伸。已生成回合在延伸时不会被重置。

四、把角色排进指定回合（自动反推前置）
从左侧图鉴、队伍初始顺序、「当前牌序」条或其他回合里，把一张卡拖到某个回合的某一格上。 程序会倒推：为了让这个角色在第 T 回合站上这个位置，前面的回合分别需要怎么排 —— 并且尽量把改动推迟到最靠后的回合， 能不动前面的排布就不动。执行后，被自动调整的格子会标「前置调整」，目标格标「目标位」。
如果做不到（比如第 1 回合只能动槽位 1-2-3，根本够不到第 2 回合的 4-5-6）， 拖拽会显示禁止光标并说明原因：它会告诉你这个角色在该回合开始前只可能出现在哪几个槽位。 队里有同名两张时，只要任意一张赶得上就能放成，程序会自动挑那一张。

五、预设库与图鉴
内置 1458 张卡（中文名 / 属性 / 链接技能 / 分类 / 头像），可按属性、稀有度筛选或搜索。 点图鉴卡右上角的 ☆ 收藏进「我的」，已收藏的会变成高亮的 ★（再点一次取消）。 自建角色与收藏都保存在浏览器本地，可用「导出预设库 / 导入预设库」备份迁移。
数据来源：DOKKAN.FYI（社区数据库，robots.txt / llms.txt 允许引用）。链接技能与分类为官方繁中译名转简体， 角色名由术语表逐词对照生成，可能与游戏内文本有出入；卡面称号保留英文原文。

六、编队（队伍预设）
队伍区顶部有一排编队快捷位。把当前 7 人存成一套编队后，点一下就能整套换人： 新编队用「＋ 存为编队」，每套编队上悬停可 ✎ 重命名、✕ 删除； 编队右侧的小色条是这套队伍 7 个槽位的属性指纹，把鼠标停在上面可以看到完整名单。
编队只保存「队伍里有哪 7 个人」、他们的初始槽位顺序，以及队长 / 助战标记，不保存回合数与手动拖出来的排程 —— 载入后会按初始顺序重新推演。当前队伍对应的那套编队会高亮显示。
队长 / 助战：队伍区上方的 👑 队长 / 🤝 助战 两个下拉框，可从当前队伍的 7 人里各指定一名 （两者可以是同一名角色，这时两枚徽标一起显示）。标记是跟着角色走的 —— 拖动改初始顺序时标记不断， 并会同步显示在队伍格、当前牌序、回合卡片、出场回合汇总上；角色被移出队伍时标记自动摘掉。 存编队时这两个标记会一并保存，载入编队时一起恢复；同 7 个人但队长不同的两套编队算作两套。
编队与角色预设一起保存在浏览器本地，也一起走「导出 / 导入预设库」， 导出的 JSON 里同时含 presets 与 teams 两段。

七、批量导入
点顶部「导入预设库」→ 粘贴符合结构的 JSON 数组即可批量入库 （字段：name / nameEn / title / type / typeEn / rarity / cls / tags / note / image / links / cats / released / sourceUrl）。 也可导入 { "presets":[…], "teams":[…] } 形式的完整备份；旧版只有 presets 的文件同样兼容。
